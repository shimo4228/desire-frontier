# desire-frontier

AI が実装コストを溶かした先で、「何を望むか」の側が枯渇する。その需要側フロンティア — AI に頼みたいことが尽きた地点にこれから人が順に到達したとき、価値はどこに宿るか — を探索し、発信する研究ライン。

起点はエッセイ「AI に頼みたいことが尽きたあと、ひとつだけ残った欲望」（note, 2026-08-13）。
https://note.com/sakamaki4228/n/n2375bfc4d521

## 4 本柱（初期の見取り図）

| 柱 | 何をするか | 置き場 |
|---|---|---|

先行論考のリンク集: [reading-list.md](reading-list.md)（2026-08-14 収集・照合済み、2026-08-15 実証研究 §6 追加）

## 隣接領域との境界（2026-08-15）

**空洞化**（AI 使用で意味・動機が下がる）と**剥奪**（望みの対象が外から取られる）は、2025〜2026 の量的実証研究が既に測定している隣接機構であり、この repo の中心対象ではない。中心対象は**枯渇** — 望みが内側から尽きる現象で、タスクを外から与える既存の実験パラダイムでは原理的に測れない。だから証言収集で追う。判別基準は [concepts.md](concepts.md) 境界節。

## 観測ループ

daily-research の `desire` line が**毎日**（他 line の輪番とは別枠で）到達者の証言・関連論考の動きを監視し、面白いものは LLM wiki へ ingest される。

## この構造は足場である

4 本柱もファイル構成も、2026-08-14 時点の見取り図であって拘束ではない。観測と実践が別の形を要求したら、構造の方を変える（scaffold dissolution）。初期コンセプトがプロジェクトの発展を阻害し始めたら、溶かすのはコンセプトの方。

Status: 2026-08-14 開始。器（DOI 化・paper 化・独立発信チャンネル等）は素材が溜まってから決める。
