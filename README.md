# desire-frontier

AI が実装コストを溶かした先で「何を望むか」の側が尽き、その地点にこれから人が順に到達する、という仮説があります。このリポジトリは、その需要側のフロンティア、つまり AI に頼みたいことが尽きた地点で価値はどこに宿るかを、証言と自己観測で確かめながら探索し、発信するための記録です。学術研究ではなく、実践者の観測と思索の記録です。

起点は著者のエッセイ「[AI に頼みたいことが尽きたあと、ひとつだけ残った欲望](https://note.com/sakamaki4228/n/n2375bfc4d521)」（note、2026-08-13）です。ソフトウェアではなく日本語の Markdown の記録なので、インストールして使うものはありません。初めて読む方は、このエッセイのあと下の「[隣接領域との境界](#隣接領域との境界)」と [concepts.md](concepts.md) へ進むのが入口です。2026-08-14 に始め、記録への取り込みは著者が手で行っており、2026-10-10 時点で最後の取り込みは 2026-08-19 です。

## 隣接領域との境界

**空洞化**（AI 使用で意味・動機が下がる）と**剥奪**（望みの対象が外から取られる）は、2025〜2026 の量的実証研究が既に測定している隣接機構で、このリポジトリの中心対象ではありません。中心対象は**枯渇**、つまり望みが内側から尽きる現象で、タスクを外から与える既存の実験パラダイムでは原理的に測れません。だから証言収集で追います。見分けるときは「AI との作業自体は楽しいか」「望みは取られたのか、湧かなくなったのか」と尋ねます。著者自身は前者に「楽しい」、後者に「湧かなくなった」と答える側で、これが枯渇の形です（[observations/2026-08-15-not-displacement.md](observations/2026-08-15-not-displacement.md)、判別基準の全体は [concepts.md](concepts.md) の境界節）。

境界にはもう一つ、**受け手の消失**があります。対象も作業の楽しさも残るのに、作ったものを受け取る第三者が消えて、やる理由が止まる機構で、Fernando Borretti の論考 "Mathematics Without Mathematicians"（2026-08-02、[reading-list.md](reading-list.md) の §3）の定式化を、この記録は起点にしています。日本語圏ではそれより前の 2026-06 に、分析としての記述が 2 本あります（[concepts.md](concepts.md) の受け手の消失の項）。証言の上では枯渇と区別がつかないため、証言を採るときは「誰か一人が確実に使ってくれると分かっていたら、それを作るか」と尋ねて分けます。作るなら受け手の消失、作らないなら枯渇です。

受け手の側は、2026-08-19 に 1 つの場でだけ代理指標を測りました。Show HN で 100 点に届いた投稿の割合（到達率）は、7 月の同月比で 2024 年の 4.41% から 2026 年の 1.69% に下がりました。ただし同じ期間に受け手は増えており、このデータが示すのは消失ではなく希釈です（数値と出典の Algolia HN Search API は [reading-list.md](reading-list.md) の §6、解釈は [concepts.md](concepts.md) の受け手の消失の項）。

証言は公開された一人称の文章から集めるので、作ることより先に人に見せることが止まるなら、前線に近い人ほど記録に現れなくなります。2026-08-19 時点で日本語圏の枯渇型の証言がゼロであることには、「まだ早い」と並んでこの説明もありえます（[concepts.md](concepts.md) の「測定器の限界」節）。

## 対抗モデル

`desire exhaustion`（枯渇）の定義は、欲望を使えば減って尽きる残量として書いています。シカゴ大の Alex Imas が Girard の模倣的欲望を実験経済学に翻訳した系列（2026-04〜06、[reading-list.md](reading-list.md) の §4）は、欲望は他者の欲望から生まれ続けるので「飽和しない」と結論します。これで、この記録が対立仮説として扱ってきた Altman 型の見方（「欲望は不変で無限」）に実験データが付きました。ただし実証は消費側（入札額）のみで、制作欲望への転写は空白です。どちらの見方が正しいかは未決のまま、[concepts.md](concepts.md) の対抗モデル節に置いています。

## 観測ループ

daily-research は著者の研究テーマごとに「ライン」を立て、輪番で選ばれたラインについて Claude Code が外部を調べてレポートを書く仕組みです。その `desire` ラインは、到達者の証言と関連論考の動きを監視するラインです。もう一つの経路は [edge-frontier](https://github.com/shimo4228/edge-frontier) です。daily-research の `edge` ラインが育てる事例台帳で、そこで見つかった証言のうち頼みたいことが尽きた型はこのリポジトリの [testimonies.md](testimonies.md) に回ってくる取り決めですが、2026-10-10 時点でこの経路から台帳に入った証言はまだありません。レポートからこのリポジトリへの取り込み（concepts / reading-list / testimonies）は著者が手で行います。

## この構造は足場である

4 本柱もファイル構成も、2026-08-14 時点の見取り図であって拘束ではありません。観測と実践が別の形を要求したら、構造の方を変えます。器（DOI 化・論文化・独立した発信チャンネル等）は素材が溜まってから決めます。
