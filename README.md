# desire-frontier

AI が実装コストを溶かした先で、「何を望むか」の側が枯渇する。その需要側フロンティア — AI に頼みたいことが尽きた地点にこれから人が順に到達したとき、価値はどこに宿るか — を探索し、発信するライン。学術研究ではなく、実践者の観測と思索の記録。

起点はエッセイ「AI に頼みたいことが尽きたあと、ひとつだけ残った欲望」（note, 2026-08-13）。
https://note.com/sakamaki4228/n/n2375bfc4d521

## 隣接領域との境界（2026-08-15）

**空洞化**（AI 使用で意味・動機が下がる）と**剥奪**（望みの対象が外から取られる）は、2025〜2026 の量的実証研究が既に測定している隣接機構であり、この repo の中心対象ではない。中心対象は**枯渇** — 望みが内側から尽きる現象で、タスクを外から与える既存の実験パラダイムでは原理的に測れない。だから証言収集で追う。判別基準は [concepts.md](concepts.md) 境界節。

2026-08-16 に第四の機構**受け手の消失**（対象も在庫も楽しさも残るが、作ったものを受け取る第三者が消えてやる理由が止まる — Borretti 2026-08-02）を追加した。証言上は枯渇と区別がつかないため判別質問を 3 問に増やした。2026-08-18 には**公開の停止**（作ることは止まらず、見せることが先に止まる）が 3 問すべてをすり抜けることが分かり、第 4 問を情報捕捉用に足した。公開が制作より先に止まるなら、公開文章を入力とするこの repo の測定器は**前線に近づくほど感度を失う**——日本語圏ゼロに「まだ早い」と並ぶ第二の説明（[concepts.md](concepts.md) 測定器の限界節）。

## 対抗モデル（2026-08-17）

`desire exhaustion` の定義は在庫モデル（消化 > 補充で残量が尽きる）で書かれている。シカゴ大の Alex Imas が Girard の模倣的欲望を実験経済学に翻訳した系列（2026-04〜06）は、欲望を他者との回路を流れる**フロー**として扱い「飽和しない」と結論する — 対立仮説（Altman 型「欲望は不変で無限」）に初めて実験データが付いた。ただし実証は消費側（入札額）のみで、制作欲望への転写は空白。在庫かフローかは未決のまま [concepts.md](concepts.md) 対抗モデル節に置く。

## 観測ループ

daily-research の `desire` line が**毎日**（他 line の輪番とは別枠で）到達者の証言・関連論考の動きを監視し、面白いものは LLM wiki へ ingest される。
