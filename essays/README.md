# essays — 価値論（そうなった時の価値とは）

Keynes・フロム・taste 論の**先**を書く思索の作業場。エッセイの公開正本は note（JA 初出）→ Substack（EN 翻訳）の既存パイプラインで、ここには種・下書き・ボツ稿を置く。

## 立っている問い（種）

- 処理能力から解放されたとき、人は何を望むのか。価値は成果物から**望む力そのもの**（serious context of use の残量）へ移るのか
- 「パイプラインに組めない問い」だけが手元に残るなら、組めない性質とは何か
- 枯渇に先に着いた側は、後から到達する人に何を渡せるのか（語彙か、観測枠組みか、処方箋の不在の証明か）
- 対立仮説（Altman 型「欲望は不変で無限」）はどの観測で棄却または支持されるか。2026-08-17 追記：対立仮説の正本を Altman（エッセイ）から Imas（実験データ付きフローモデル、[concepts.md](../concepts.md) 対抗モデル節）へ移すべきか。移すなら、対立の形が「欲望の総量」から「欲望は在庫かフローか」へ変わる。2026-08-18：Imas は作り手の欲望を論じていない（"Someday we will all be artists" も消費側）ので「移さない」側に傾く
- 欲望が在庫ではなくフロー（他者の欲望から湧く）なら、「頼みたいことが尽きた」の正しい問いは「なぜ補充が遅いか」ではなく「誰との回路が切れたか」になる。起点エッセイの N=1 は「回路が最も細い条件（非生計依存・個人制作）で観測された極値サンプル」と読み直せるか（2026-08-17）
- Borretti の格下げ論（2026-07-28）：「人が心配するのは貧困と意味だが、もっと心配すべきは disempowerment だ」。望みが尽きる前に、望みを実行に移す物質的な力の方が先に失われるなら、需要側フロンティアは構造的に到達されない。意味・望みの問いは、無力化という上位変数が固定されている間だけ立つ問いなのか（2026-08-16）
- 先に止まるのが制作ではなく公開なら、「AI に頼みたいことが尽きた」より手前に「作ったものを見せる気が失せた」がある。公開が「他者に自分の存在を認めさせる」機能を持つなら、AI 時代に壊れるのは作る楽しさではなくその機能——価値は成果物からでも望む力からでもなく、**見せる回路**から先に抜けるのか（2026-08-18）
- 「作れば誰かが使う」が崩れたあと（受け手の消失）、作る理由はどこから来るか。自己決定理論の自律性・有能感（観衆不要）で持つ人と、Borretti の言う「ごく、ごく少数」の外側にいる人の分岐（2026-08-16）

種は自由に足す。育ったら note 正本へ、その時のレビュー chain は zenn-content 側の規約に従う。
