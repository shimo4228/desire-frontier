# essays — 価値論（そうなった時の価値とは）

Keynes・フロム・taste 論の**先**を書く思索の作業場。エッセイの公開正本は note（JA 初出）→ Substack（EN 翻訳）の既存パイプラインで、ここには種・下書き・ボツ稿を置く。

## 立っている問い（種）

- 処理能力から解放されたとき、人は何を望むのか。価値は成果物から**望む力そのもの**（serious context of use の残量）へ移るのか
- 「パイプラインに組めない問い」だけが手元に残るなら、組めない性質とは何か
- 枯渇に先に着いた側は、後から到達する人に何を渡せるのか（語彙か、観測枠組みか、処方箋の不在の証明か）
- 対立仮説（Altman 型「欲望は不変で無限」）はどの観測で棄却または支持されるか

種は自由に足す。育ったら note 正本へ、その時のレビュー chain は zenn-content 側の規約に従う。
