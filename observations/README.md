# observations — 定点観測（一人称の縦断記録）

起点エッセイは「枯渇した時点」の N=1 スナップショット。ここはその続き — 枯渇の**あと**に何が起きるかの縦断記録を置く。折り返した欲望はどこへ向かったか、週次レビューに縮んだ偏愛はその後どうなったか。先行して到達した人間にしか書けない、時間が資産になる記録。

- 形式・カデンツは未確定（足場）。書きたいときに `YYYY-MM-DD-<slug>.md` で置くところから始める
- 記録は observation であって essay ではない。磨かない。日付と事実（内的事実を含む）を優先する
- ここから概念（→ [../concepts.md](../concepts.md)）やエッセイ（→ [../essays/](../essays/)）が育ったら、その時点で昇格させる
